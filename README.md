# 台灣小吃盲盒圖鑑：全台美食大百科

歡迎來到 **[台灣小吃盲盒圖鑑](https://jasminechuang.github.io/taiwanfood/)**！這是一個蒐羅全台經典好味道、結合趣味盲盒機制的互動網頁專案。挑戰解鎖並收集全台美食，集滿您的專屬美食圖鑑！

### 核心功能
* **美食盲盒開箱**：消耗美食券隨機解鎖道地的台灣傳統小吃與在地美食。
* **圖鑑收集進度**：即時追蹤您的美食收集進度（目前圖鑑收集進度為 17 / 24）。
* **美食券系統**：支援每日領取美食券，累積代幣持續開箱驚喜。

# Taiwan Food Mystery Box Encyclopedia: Encyclopedia of Taiwanese Delicacies

Welcome to the **[Taiwan Food Mystery Box Encyclopedia](https://jasminechuang.github.io/taiwanfood/)**! This is an interactive web project that collects classic flavors from all across Taiwan, combining them with an engaging mystery box mechanic. Challenge yourself to unlock and collect Taiwanese delicacies to complete your personal food encyclopedia!

### Key Features
* **Mystery Box Unboxing**: Consume food vouchers to randomly unlock authentic traditional Taiwanese snacks and local delicacies.
* **Collection Progress**: Real-time tracking of your food collection progress (currently at 17 / 24 items collected).
* **Voucher System**: Daily claiming of food vouchers to accumulate tokens and continuously unlock new surprises.
